# Spec 001: Contracts

아직 정의되지 않음. 이 파일에는 다음에 대한 구체적인 request/response contract(OpenAPI로 기술)가 채워질 예정이다:

- Source / Source Event / Target / Subscription 등록 API
- 생성된 Ingress endpoint의 형태
- Canonical Event 및 Delivery Attempt 조회 API

Phase 1 구현 계획 단계에서, `docs/architecture/system-design.md`의 등록 모델과 canonical event 스키마를 기준으로 채워질 예정이다. 구현에 앞서 여기서 임의로 필드명을 만들어내지 말 것 — `system-design.md`와 `spec.md`로부터 도출할 것.
